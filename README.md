# akshatgg/homebrew-tap

Homebrew casks for [Souffleur](https://getsouffleur.vercel.app).

```bash
brew install --cask akshatgg/tap/souffleur
```

Installing through Homebrew removes the download quarantine flag, so macOS does
not show the *"Apple could not verify"* dialog. That is the same permission the
System Settings button grants, applied on your behalf — it does not mean the app
is notarised.

Source: [akshatgg/Souffleur](https://github.com/akshatgg/Souffleur)
