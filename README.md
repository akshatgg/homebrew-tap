# akshatgg/homebrew-tap

Homebrew casks for [Souffleur](https://getsouffleur.vercel.app), [Loupe](https://loupeapp.vercel.app) and
[Buddy](https://buddywrites.vercel.app).

```bash
brew install --cask akshatgg/tap/souffleur
brew install --cask akshatgg/tap/loupe
brew install --cask akshatgg/tap/buddy
```

`akshatgg/tap/loupe` is always the newest Loupe release. To install an older
one, name its version — uninstall the current one first:

```bash
brew uninstall --cask loupe
brew install --cask akshatgg/tap/loupe@2.0.0
```

The Loupe casks are generated by `packaging/update-cask.js` in
[akshatgg/loupe](https://github.com/akshatgg/loupe) and updated by its Release
workflow, which adds a `loupe@<version>` cask for every release.

The Buddy cask is written by `tools/homebrew-cask.js` in
[akshatgg/Buddy](https://github.com/akshatgg/Buddy) and updated by its Release
workflow for every Mac release. Buddy updates itself (Update now), so
`brew upgrade` leaves it alone.

Installing through Homebrew removes the download quarantine flag, so macOS does
not show the *"Apple could not verify"* dialog. That is the same permission the
System Settings button grants, applied on your behalf — it does not mean the app
is notarised.
